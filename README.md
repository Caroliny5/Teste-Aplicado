# Teste-Aplicado

Este repositório centraliza projetos de teste e experimentação.

## Legenda dos itens do repositório

| Tipo | Legenda | Função |
|---|---|---|
| Projeto | Conjunto de arquivos com um objetivo específico | Implementar e documentar uma solução (ex.: app, script, experimento) |
| Documento de especificação | Descrição funcional e técnica do projeto | Explicar objetivo, escopo, tecnologias e como usar |
| Pasta de código-fonte (`src/`) | Código principal do projeto | Implementar funcionalidades |
| Pasta de testes (`tests/`) | Testes automatizados | Validar o comportamento esperado |
| README do projeto | Guia rápido do projeto | Orientar instalação, execução e estrutura |

## Especificações dos projetos incluídos

### 1) Projeto: Teste-Aplicado (raiz)
- **Objetivo:** Testar sites online que permitem criação de soluções em HTML, JavaScript, C++, Python, etc.
- **Escopo atual:** Repositório base para organização e documentação de projetos.
- **Tecnologias esperadas:** HTML, JavaScript, C++, Python e outras conforme novos projetos.

## Padrão para novos projetos

Sempre que um novo projeto for incluído neste repositório, registrar:
1. **Nome do projeto**
2. **Objetivo**
3. **Função principal**
4. **Tecnologias usadas**
5. **Estrutura de pastas/arquivos**
6. **Como executar/testar**
